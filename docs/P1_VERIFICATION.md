# P1 — объявления и повторная проверка P0

Завершено 10 ноября 2026 года. Миграция `20261109161926_AddListings` успешно применена к локальной базе после резервного копирования и проверок на временных базах.

## Реализовано

- Кабинет «Мои объявления»: `#listings`, создание `#listing`, редактор `#listing?id=...`.
- Отдельные таблицы Listings, ListingContact, ListingImages и Cities; прежние товары, пользователи и заказы сохраняются.
- Частичные черновики; цена может быть не заполнена в черновике, 0 ₽ означает бесплатную вещь.
- Публикация требует заголовок, описание, цену, категорию, город, состояние, фото, телефон и явное согласие на его показ.
- Draft → Published → Unpublished/Sold; Sold → Unpublished; Unpublished/Sold → Archived. Архив доступен только для чтения.
- Проверка владельца и версии при изменении, смене статуса и операциях с фото. Чужой объект — 404, устаревшая версия — 409.
- Изменение телефона в форме снимает согласие; дата согласия хранится отдельно. Профиль не меняет контакт уже созданного объявления.
- Отзыв согласия, неполные обязательные поля и удаление последнего фото снимают публикацию. Флаг скрытия модератором блокирует публикацию; инструменты модератора относятся к P3.
- До 10 фотографий с проверкой содержимого и перекодированием. Скрытые фото доступны владельцу; опубликованные — всем.

Начальные города: Иркутск, Ангарск, Шелехов, Москва, Санкт-Петербург, Новосибирск. Это стартовый справочник, не полный список населенных пунктов.

## Что остается в P2

Публичный каталог пока показывает старые товары. Новые объявления доступны в кабинете автора; публичный поиск и endpoint показа телефона еще не подключены. Старые торговые API действуют до безопасного переключения P2.

Перенос старых карточек с сохранением ID/фото выполняется в P2 одновременно с остановкой старых писателей. Автоматическая копия в P1 создала бы два изменяемых источника с расходящимися данными. P1 добавляет совместимую схему и готовый сценарий автора.
