## Повторный запуск

Из корня проекта, при работающем Compose PostgreSQL и настроенных User Secrets:

```powershell
./scripts/Verify-P0.ps1
```

Скрипт выведет путь к `result.json`. Он проверяет сборку/тесты, создает три базы с уникальными именами `neavito_p0_*`, проверяет миграции и восстановление. При сбое временные базы остаются для диагностики. Основную базу не удаляет. Рассчитан на локальную базу `neavito`, порт 15432. Для сравнения копии с источником исключить параллельную пользовательскую запись.

В отдельном терминале:

```powershell
./scripts/Start-P0Server.ps1 -ReportPath <путь-к-result.json>
```

Сервер использует новую временную базу, отдельные каталоги почты/файлов/ключей и HTTPS-порт 7253. Нужен локальный ASP.NET development certificate. При доступном пакете Playwright и установленном Edge:

```powershell
node scripts/verify-auth-browser.cjs <путь-к-result.json>
```

Если Playwright установлен в другом каталоге, указать его `node_modules` в `NODE_PATH`. Затем остановить тестовый сервер и удалить только созданные им базы:

```powershell
./scripts/Clear-P0Databases.ps1 -ReportPath <путь-к-result.json>
```
