# P2: публичные объявления и проверка

Дата: 10 ноября 2026. Реализован публичный каталог доски объявлений и безопасный переход со старого торгового сценария.

## Результаты

- Итоговая сборка без предупреждений/ошибок; **74 серверных теста прошли, 0 пропусков** с `NEAVITO_TEST_POSTGRES=1`. Модель EF соответствует миграции.
- Повторно проверены авторизация, подтверждение/восстановление по локальным письмам, глазок пароля, изменение профиля/пароля, отзыв сессий, ошибки и CSRF-заголовок.
- Проверены черновики, обязательные поля, фото и ограничения загрузки, согласие, переходы статусов, чужой доступ, конфликт версии и конкурентные изменения PostgreSQL.
- Новые тесты: комбинированные фильтры и поиск по описанию, бесплатные вещи, сортировки и пагинация, ошибочные параметры, отсутствие контакта в публичных DTO, 401 для гостя, no-store, 10 запросов/аккаунт и 30/IP за 15 минут, Retry-After.
- Снятые, проданные, архивные, скрытые объявления и объявления заблокированного/неподтверждённого автора закрываются в каталоге, карточке, фото и контакте. Заблокированный пользователь теряет действующую сессию и не может войти.
- Старые торговые записи возвращают 410 вошедшему пользователю (гостю — 401 на защищённых маршрутах); права чтения истории сохранены. Старые публичные URL перенаправляются на новые, кабинетные ссылки — на объявления.
- PostgreSQL: пустая база, повторная миграция, обновление старой схемы и сохранение аккаунта; резервная копия восстановлена и содержимое таблиц сверено. Затем проверенная восстановленная копия обновлена до P2 перед обновлением основной базы.
- Отдельный тест миграции проверяет отказ при активном заказе без частичного переноса, сохранение ID/автора/цены/фото, отсутствие переноса личных контактов, Draft/Unpublished, сохранение исторического заказа, запрет старых писателей на всех шести таблицах, запрет опасного Down.
- В реальном Edge с HTTPS и отдельным PostgreSQL прошли `verify-auth-browser.cjs`, `verify-listings-browser.cjs`, `verify-catalog-browser.cjs`: вход/почта/безопасность, полный цикл объявления, 13 карточек и пагинация, совместные фильтры, гостевой переход ко входу с возвратом, явный показ телефона, возврат к фильтрам, снятие объявления и недоступность контакта. Нет ошибок JavaScript. Ширины 390/768/1440 без горизонтального переполнения; снимки сохранены, мобильный каталог просмотрен визуально.

## Повторение и границы проверки

Команды и порядок запуска приведены в README. PowerShell-скрипты следует запускать через **PowerShell 7 (`pwsh`)**: Windows PowerShell 5 теряет кавычки SQL при передаче аргументов Docker. Пробный запуск через PowerShell 5 остановился на тестовой базе; пользовательские данные не затронуты. Повтор через PowerShell 7 прошёл.

Старые регрессионные тесты торговли работают в специально включённом `Testing` режиме на изолированных схемах; это не проверка доступности покупки в новой версии. Актуальный запрет отдельно проверен в API и реальной миграции PostgreSQL.

Проверка охватывает реализованные сценарии локального приложения. Производственный SMTP, публичный TLS через Caddy/Let's Encrypt, распределённые лимиты Redis, нагрузка и DDoS, Kafka, Kubernetes и интерфейс модерации ещё не реализованы и не заявляются проверенными. Их задачи сохранены в P3–P5. Телефон не сохраняется в браузерном кеше приложения, очищается при уходе со страницы/вкладки; уже увиденный пользователем номер технически отозвать невозможно.
